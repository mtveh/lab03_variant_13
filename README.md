## 1. Постановка задачи

Построить условную карту парковочных мест. Для каждой позиции (уровень, ряд, место) назначить категорию по приоритету:

| Приоритет | Категория | Условие |
|---|---|---|
| 1 | **D** — доступное место | ряд 1 и номер места не больше 2 |
| 2 | **E** — зарядка | номер места кратен 5 |
| 3 | **R** — резерв | сумма трёх координат (f + r + p) кратна K |
| 4 | **O** — обычное | ни одно условие выше не выполнено |

Вывести карту каждого уровня и количество мест каждой категории.

### Входные данные и ограничения

| Величина | Смысл | Ограничение |
|---|---|---|
| F | количество уровней | 1 ≤ F ≤ 20 |
| R | количество рядов на уровне | 1 ≤ R ≤ 20 |
| P | количество мест в ряду | 1 ≤ P ≤ 20 |
| K | делитель для категории R | K ≥ 1 (при K = 0 возникло бы деление на ноль) |

Ввод проверяется до начала основного вычисления: при нечисловом вводе или нарушении ограничений программа выводит сообщение и завершается с кодом 1.

### Принятые трактовки условия

- Нумерация уровней, рядов и мест начинается с 1.
- «Ряд 1» — первый ряд **на каждом** уровне.
- «Номер кратен 5» — номер места p в ряду (в той же фразе условия правило D говорит о «номере места»).

### Результаты

- карта каждого уровня: построчно по рядам, по одному символу на место;
- количество мест категорий D, E, R, O;
- `iter` — число выполнений тела внутреннего цикла (должно равняться F·R·P).

## 2. Алгоритм

### Псевдокод

```
НАЧАЛО
  Ввести F, R, P, K
  ЕСЛИ введено не 4 целых числа → вывести «Ошибка ввода», завершить с кодом 1
  ЕСЛИ F, R или P вне [1; 20] → вывести ошибку, завершить с кодом 1
  ЕСЛИ K < 1 → вывести ошибку, завершить с кодом 1

  cntD = 0, cntE = 0, cntR = 0, cntO = 0, iter = 0

  ДЛЯ f ОТ 1 ДО F                      // внешний цикл: уровни
    вывести «этаж: f»
    ДЛЯ r ОТ 1 ДО R                    // средний цикл: ряды
      вывести «ряд: r»
      ДЛЯ p ОТ 1 ДО P                  // внутренний цикл: места
        iter = iter + 1
        ЕСЛИ r = 1 И p ≤ 2           → вывести D, cntD + 1
        ИНАЧЕ ЕСЛИ p mod 5 = 0       → вывести E, cntE + 1
        ИНАЧЕ ЕСЛИ (f+r+p) mod K = 0 → вывести R, cntR + 1
        ИНАЧЕ                        → вывести O, cntO + 1
      КОНЕЦ ДЛЯ p
      перевод строки
    КОНЕЦ ДЛЯ r
  КОНЕЦ ДЛЯ f

  Вывести cntD, cntE, cntR, cntO, iter
КОНЕЦ
```

### Описание циклов

| Уровень вложенности | Переменная | Границы | Назначение |
|---|---|---|---|
| Внешний | f | от 1 до F | перебор уровней парковки, вывод заголовка уровня |
| Средний | r | от 1 до R | перебор рядов уровня, каждый ряд — одна строка карты |
| Внутренний | p | от 1 до P | перебор мест ряда, назначение и вывод категории |

- Все границы постоянные, каждая позиция (f, r, p) посещается ровно один раз. Всего итераций внутреннего цикла: **F · R · P**.
- **Почему циклы завершаются:** управляющие переменные увеличиваются на 1 в заголовке `for` и не изменяются в теле, верхние границы фиксированы и не больше 20.
- **Почему нет повторного учёта:** категория выбирается одной цепочкой `if … else if … else`, поэтому каждое место получает ровно одну букву. Перестановочных дублей в задаче нет: тройка (f, r, p) — это координаты, а не неупорядоченный набор. Контроль: `cntD + cntE + cntR + cntO = iter`.
- **break и continue не используются:** по условию нужно обойти и вывести все позиции, досрочный выход не нужен.
- Массивы, строки для хранения данных, структуры, рекурсия не используются: каждый символ выводится сразу, итоги хранятся в четырёх счётчиках.

## 3. Блок-схема

![Блок-схема](flowchart.png)

Исходник: `flowchart.drawio`.

Соответствие схемы программе:
- ввод и три проверки допустимости (ромбы) с выходом на «Конец» по ветке «нет»;
- блок инициализации счётчиков и `iter` перед внешним циклом;
- три цикла, каждый в виде «инициализация → ромб условия → тело → изменение переменной → возврат к ромбу»;
- в теле внутреннего цикла `iter + 1` и цепочка ромбов D → E → R с веткой O; после любой ветки выполняется `p = p + 1`;
- по ветке «нет» каждого ромба цикла происходит выход на внешний уровень, после внешнего цикла выводятся итоги.

| 10 | Некорректный ввод | `a b c d` | «Ошибка ввода» | | |

### Обоснование ожидаемых значений

- **iter** = F · R · P во всех тестах.
- **D** = F · min(P, 2): два первых места первого ряда на каждом уровне.
- **E** = F · R · ⌊P / 5⌋: E не пересекается с D (места 1–2 не кратны 5).
- **Тест 2.** R: на уровне 1 клетки (1,1,6), (1,2,1), (1,3,4); на уровне 2 клетки (2,2,4), (2,3,3) — суммы 8, 4, 8, 8, 8 кратны 4. Итого R = 5, O = 36 − 4 − 6 − 5 = 21.
- **Тест 3.** Среди мест 1, 2, 3 в каждом из 20 рядов ровно одно даёт сумму, кратную 3. На уровнях 1, 3 и 4 в первом ряду это место попадает на p ≤ 2 и становится D, поэтому R = 20 − 3 = 17.
- **Тест 4.** P = 4 — номер места никогда не кратен 5; максимальная сумма 1 + 2 + 4 = 7 < 10 — R невозможна.
- **Тест 5.** Клетка (1,1,1): сумма 3 кратна K = 1, но приоритет D выше.
- **Тест 6.** При K = 1 любая сумма кратна K, поэтому все места, не ставшие D или E, получают R: 8000 − 40 − 1600 = 6360.
- **Тест 7.** Клетка (1,2,5) с суммой 8 подходит и под E, и под R; выбирается E. Клетка (1,1,1) с суммой 3 не кратна 4, а (1,2,1) с суммой 4 — R.

Подтверждения: `evidence/control_run.png` (тест 1), `evidence/boundary_run.png` (граничный тест).

Вход: F = 1, R = 2, P = 5, K = 3. Прочерк «—» означает, что проверка не выполнялась, потому что раньше сработала ветка с более высоким приоритетом.


## 9. Вывод

Разработана программа с тремя вложенными циклами (уровень → ряд → место), которая строит карту парковки и подсчитывает места каждой категории без использования массивов: символ выводится сразу, итоги хранятся в отдельных счётчиках. Приоритет категорий обеспечивается цепочкой `else if`, поэтому каждая позиция получает ровно одну категорию. Корректность подтверждена ручной трассировкой, тестами на границах, на отсутствие категорий и на некорректный ввод, а также инвариантом D + E + R + O = iter = F·R·P. Проверка ввода до циклов исключает деление на ноль при K = 0. Работа с AI показала, что его замечания полезны для поиска граничных тестов, но требуют проверки: одно из них оказалось ошибочным, так как AI видел только псевдокод, а не реальный вывод программы.
